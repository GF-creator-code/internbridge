# 简历匹配、AI 投递与通知

## 连接自己的模型

打开「设置中心 → 连接与通知」，填写模型地址（Base URL）、API 密钥和服务商的模型 ID，点击「保存配置」。配置保存在本机数据库。模型调用和计费由所选服务商处理。

## 从简历到岗位匹配

1. 切到「设置中心 → 简历与匹配」，选择文字版 PDF、DOCX 或 UTF-8 TXT，最大 10 MB。选好文件就会开始解析，文字会发送至配置的模型。扫描版 PDF 可先转为文本。
2. 核对每项技能旁的简历原文。点击「加入并保存所选技能」追加到投递介绍，已有内容会保留。也可选择「先加入草稿」，在下方调整表述后点击「保存修改」。
3. 在「职位描述」粘贴岗位职责及任职要求，点击「分析岗位匹配」。可以使用尚未保存的介绍试算。每个匹配项附有技能介绍原文，暂缺依据的要求可用来检查是否漏写了相关经历。

## 投递时使用技能介绍

Boss直聘、JobsDB 和 OfferToday 在启用各自的投递 AI 开关后读取已保存的技能介绍。Boss直聘 的开关也可在「简历与匹配」分区设置。JobsDB 默认只采集，开始采集不会提交申请。

## 企业微信通知

如需通知，在「设置中心 → 连接与通知」展开「企业微信通知」，填写群机器人的 Webhook 地址，开启发送后保存。通知未送达时，可在运行日志中检查发送结果。

API 密钥和 Webhook 地址属于私密配置，分享截图时请遮住这些字段。
