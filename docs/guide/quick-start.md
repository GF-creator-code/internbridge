# 快速上手

在自己的电脑上启动 InternBridge 后，可采集职位、整理两地职位用的简历技能，在投递前粘贴一份职位描述试算，并在数据看板里复盘每日投递与回复。

## 1. 启动本机投递工作台

Windows 需要 Git、JDK 21、Node.js 22.13 或更高版本，以及 Corepack 或 pnpm。将 JDK 安装目录设为 `JAVA_HOME`。第一次启动需要联网获取构建依赖。

```powershell
git clone https://github.com/GF-creator-code/internbridge.git
cd internbridge
powershell -File .\start-local.ps1
```

脚本首次运行时从上游 v2.0.1 下载数据库模板，校验后放到 `db/getjobs.db`。已有数据库会直接使用。Gradle 会构建管理页面并启动服务，打开本机的 [投递工作台](http://127.0.0.1:9527/)。

macOS 或 Linux 用户可在项目根目录创建 `db` 目录，将上游的 `getjobs.db.template` 保存为 `db/getjobs.db`，然后运行 `./gradlew bootRun`。Windows 无法连接下载站时也可手动放置同一模板。[上游 v2.0.1 发布页](https://github.com/loks666/get_jobs/releases/tag/v2.0.1)

## 2. 在设置中心完成四个分区

侧边栏「工作台」分组里的「设置中心」是唯一需要填全局信息的地方，四个分区各管一件事：

| 分区 | 要填的内容 |
| --- | --- |
| 连接与通知 | 模型地址、密钥、模型名称；可选的企业微信机器人 |
| 求职档案 | 工作形式（不限 / 实习 / 兼职 / 全职 / 校园招聘）、学历、到岗时间、简历路径与联系方式 |
| 全局规则 | 意向城市（保存后点「应用到各平台」同步）与所有平台共用的黑名单 |
| 简历与匹配 | 技能介绍、投递提示词、AI 开关与简历解析 |

意向城市只在「全局规则」编辑，技能介绍只在「简历与匹配」编辑；「求职档案」里显示的是只读摘要，改内容请切到对应分区。

## 3. 选平台、登录并投递

在「内地 / 香港」分组选一个平台。先点「登录」在浏览器窗口完成扫码或账号登录，登录态保存在本机；改完配置点「保存配置」，再点「开始投递」。存在未保存的修改时，投递会被拦下并提示，避免用上一次的关键词跑一轮任务。进度会实时显示在页面上，多个平台可同时运行。

JobsDB 默认只采集，职位名称可从「投递分析」打开原站；OfferToday 只处理「實習」类型卡片；实习僧整站均为实习岗，投递前需在原站选好附件简历。

## 4. 从简历提取技能、试算匹配

上传文字版 PDF、DOCX 或 UTF-8 TXT（最大 10 MB），简历文字会发送到配置的模型。核对技能旁的简历原文：「加入并保存所选技能」把勾选项追加到已有介绍，「先加入草稿」可以先调整文字。

在「职位描述」粘贴繁中、简中或英文的岗位要求，页面会列出有简历原文支持的要求，以及现有介绍中暂缺依据的要求。试算匹配本身不会投递。

## 5. 看数据看板与每日日报

「投递数据看板」按平台汇总采集、投递、打招呼与回复，并列出有回复的岗位。每天 21:00 自动生成前一天的日报并推送到企业微信机器人（需先在「连接与通知」开启），也可以随时手动生成。需要逐条核对记录时，进入对应平台的「投递分析」标签页，应用筛选后可打开原站或导出 CSV。

## 更新已有安装

保留 `db/getjobs.db`，在运行服务的终端按 Ctrl+C，拉取最新代码后执行以下命令，重新生成页面并启动配套后端。

```powershell
git pull --ff-only
powershell -File .\start-local.ps1 -PrebuildFrontend
```
