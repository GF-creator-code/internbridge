# ⚙️ 核心与平台配置详解

InternBridge 的网页端提供统一「设置中心」和七个平台配置页。所有常规筛选参数都可以交互式填写并一键保存到本地 SQLite 数据库，无需改配置文件。

---

## 1. 设置中心：全局配置只有一个入口

侧边栏「工作台 → 设置中心」包含四个分区。每份数据只在自己的分区里编辑，避免在多个页面改同一项却不知道哪份生效：

| 分区 | 负责的全局设置 |
| :--- | :--- |
| **连接与通知** | 模型地址、密钥、模型名称，企业微信机器人 Webhook；密钥读取时只显示末四位 |
| **求职档案** | 工作形式、最高学历、可到岗时间、简历路径、邮箱与手机号；修改后对所有平台生效 |
| **全局规则** | 意向城市（保存后一键同步到各平台）、公司 / 职位 / 招聘者黑名单 |
| **简历与匹配** | 技能介绍、AI 提示词、Boss直聘 的 AI 开关与简历解析 |

平台自己的关键词、薪资、投递间隔等筛选项仍留在各自的平台页。改完务必点「保存配置」；存在未保存的修改时，投递会被拦下并提示。全局黑名单不再有第二套管理界面。

## 2. 各招聘平台专属配置

### 🟢 Boss直聘配置

#### 向已沟通 Boss 再次发送消息

在管理页「Boss直聘 → 投递行为」中切换此拨片，默认关闭。

- **关闭**：按钮为「继续沟通」时跳过该岗位，继续处理下一个。
- **开启**：点击「继续沟通」后，从页面可编辑的消息列表中随机选取一条非空行发送，不调用首次沟通的 AI 生成流程。默认提供六句，可自由增删改；清空列表时跳过重复沟通。
- 修改后点击「保存配置」，在下次启动投递时生效。「立即沟通」不受此开关影响，图片简历由原有独立开关控制。

旧数据库在启动时自动补充此配置，默认关闭，保留已有设置。

- **打招呼限额**：目前平台限制单日约 150 次。
- **自定义打招呼语**：
  - 若开启 AI 打招呼模式，系统将动态调用模型结合你的简历和 JD 生成；
  - 若未开启 AI，请务必在配置项中预留默认打招呼语文本，否则可能导致投递中断。
- **图片简历（`sendImgResume`）**：
  - 设为 `true` 后，打招呼成功的同时自动向 HR 附送预先转换好的 `resume.jpg` 图片简历。
- **黑名单自学习机制**：
  - 系统在遍历沟通记录时，如果检测到 HR 回复“不合适”、“已招满”等关键词，会自动将该企业记录至黑名单中，未来绝不重复打扰。

## 3. Cookie 管理与扫码登录

InternBridge 使用扫码登录与本地登录态管理。具体登录方式以平台页面为准，猎聘与智联按 README 要求使用绑定微信的账号：

1. **自动调起**：点击平台“登录/扫码”按钮后，本地会自动调起浏览器窗口并打开平台登录页。
2. **手机扫码**：在弹出的浏览器中，使用手机端对应 App 扫码确认。
3. **安全持久化**：登录成功后，程序在本机保存登录状态。请妥善保护本地 Cookie、浏览器数据与数据库，不要上传或分享这些文件。
4. **免重新扫码**：绝大多数平台 Cookie 有效期在 3~7 天以上，过期前无需反复扫码。

::: warning 平台维护范围
智联招聘与 51job 的实现来自上游，页面结构与风控变化较快，投递前请先在原站确认账号、简历与岗位要求。上述说明供已有用户参考，不保证当前版本仍可正常投递。
:::
