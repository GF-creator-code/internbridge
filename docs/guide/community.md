# 社区与反馈

欢迎交流求职经验、技术问题与使用心得。

## 反馈问题

遇到问题时，请提供：

- 操作系统与 JDK / Node.js 版本
- 复现步骤
- 已脱敏的日志（请务必移除 Cookie、API Key、手机号与个人简历内容）

可通过本项目 GitHub 仓库的 Issues 提交反馈。

## 贡献代码

1. Fork 本项目并创建分支
2. 完成修改后提交 Pull Request
3. 提交信息请遵循项目约定（例如 `🐛 fix: 修复 Cookie 注入失败`）
