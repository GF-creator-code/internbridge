# Get Jobs 项目介绍

Get Jobs 是给香港学生使用的本机实习申请管理端，同时覆盖香港与内地岗位。平台账号各自登录，简历技能介绍可以共用。配置和岗位记录保存在本机 SQLite 数据库，启用 AI 后，相应的文本会发往你配置的模型。

## 选择平台

| 地区 | 平台 | 日常使用 |
| --- | --- | --- |
| 香港 | JobsDB | 用英文关键词采集岗位，在「投递分析」打开原站链接。默认只采集。实验性的 Quick apply 使用本人在 SEEK 已填写的资料。 |
| 香港 | OfferToday | 按繁中关键词查找实习。登录可能需要在平台窗口手动完成，完整发送流程仍待实账验证。 |
| 内地 | 实习僧 | 按关键词、城市和个人筛选条件查找实习，申请前在原站选好附件简历。 |
| 内地 | BOSS 直聘 | 设置关键词、城市和岗位类型，可以使用已保存的技能介绍生成问候，支持上传图片简历。 |
| 内地 | 智联招聘、猎聘、51job | 各有独立的配置页。先在招聘网站确认账号、简历和职位要求，再开启任务。 |

## 简历与岗位匹配

在「环境配置」保存模型地址、密钥和名称。进入「简历与 AI 匹配」，上传文字版 PDF、DOCX 或 UTF-8 TXT。系统列出每项技能及其简历原文，可以保存选中的技能，也可先编辑草稿。

粘贴一份繁中、简中或英文职位描述，查看哪些要求有原文支持，哪些还需要补充经历。保存后的介绍可用于启用了 AI 的 BOSS 直聘、JobsDB 和 OfferToday。

## 使用入口

日常使用打开本机的 `http://127.0.0.1:9527`。桌面从侧边栏选择平台，手机点击「导航」。每个平台的记录从该页「投递分析」进入。安装及更新命令见[快速开始](/guide/quick-start)。
